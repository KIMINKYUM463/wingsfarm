# 상세페이지 고도화 계획 (v1.8 — 구현 완료)

> 요청(2026-10-30): "후커블은 상세페이지 맨 위에 영상이 나온다. 이미지를 생성할지 말지 미리 고르게 하고, 생성하면 첨부 사진 기반으로 다양한 장면, 생성 안 하면 공백. 상세페이지를 엄청 고도화."
> 대상: 농수산물 위탁판매 수강생. 상세페이지 = 스마트스토어 860px · 쿠팡 780px 이미지 상세.

## 결정 (사용자 확인)
| 질문 | 결정 |
|---|---|
| 움직이는 컷 방식 | 기본 **천천히 줌·이동 GIF(무료, ffmpeg)** + 선택 **AI 영상(5초 ≈ 700원)** |
| AI 컷 생성 실패 | **빈칸** + "다시 만들기" 안내 (올린 사진으로 대체하지 않음) |
| 빈 자리가 남은 채 다운로드 | "빈 자리 N곳" **경고 후** 연한 회색 칸으로 내보냄 |
| 기본 이미지 모드 | AI 연출 사진 (빈칸은 카드 하나로 전환) |

## 외부 사실 (2026-10-30 확인)
- 후커블: 히어로에 "메인 GIF"(과즙 흐르는 연출 등), GIF는 그로스 요금제(월 69,000원)부터.
- Gemini Veo 3.1은 2026-10-22 종료 → `gemini-omni-1.1-flash` (Interactions API `POST /v1beta/interactions`, image_to_video, 3~10초, 16:9/9:16, 720p ≈ $0.10/초, 오디오 항상 포함 → 서버에서 제거).
- 스마트스토어·쿠팡 상세는 GIF 이미지를 받는다. **GIF 용량 한도는 공식 확인 못 함** → 10MB 이하로 맞춤.

## 구현
### A. 이미지 모드 (입력 → 기획 → 생성)
- `DraftInput.imageMode: 'ai' | 'blank'`, `DraftCut.source: 'ai' | 'own' | 'blank'` (`shared/lib/draftMedia.ts`).
- 기획: blank 모드면 전 컷 `blank`. ai 모드면 proof 컷(사진 있을 때)만 `own`, 나머지 `ai`. 섹션마다 다른 장면 힌트(`SCENE_IDEAS`), 참고 사진 인덱스를 섹션 위치로 돌려 씀, 제품 동일성 규칙.
- 기획 화면: 컷마다 AI 생성 / 내 사진 / 비워두기, 하단에 장수·빈 자리·움직이는 컷·예상 비용, "모두 AI / 모두 비워두기".
- 생성: blank → 자리 그대로, ai 실패 → 빈칸 + 완료 메시지 "N장은 비워 뒀어요".

### B. 맨 위 움직이는 컷
- 흐름: 맨 위 섹션 첫 사진 자리 → 클립(MP4, 자리 크기, 5초 24fps, 무음)
  - pan: ffmpeg zoompan(12% 줌 + 이동)
  - video: Omni 영상 → 자리 비율로 crop. 실패하면 pan으로 대체 + 안내.
- 상태는 프로젝트 레코드 `heroMotion`(pending/ready/failed). 10분 넘은 pending은 실패로 보여 줌. 사진을 바꾸면 "다시 만들기" 표시(stale).
- GIF: 클라이언트가 맨 위 섹션을 "사진 아래 레이어 / 사진 위 레이어(투명)" PNG 두 장으로 → 서버 ffmpeg가 아래 → 클립 → 위 순서로 합성, palettegen. 10MB 넘으면 fps → 크기 → 색 수 순으로 단계 축소.
- 에디터: 상단 칩 "▶ 맨 위 움직이는 컷" → 미리보기 영상, 플랫폼 너비별 GIF 받기, 업로드 안내, 다시 만들기.

### C. 빈 자리 경험
- 캔버스: 빈 사진 자리에 점선 + "사진을 넣어 주세요" 안내(내보내기에서는 숨김).
- 상단 칩 "빈 사진 자리 N곳" → 누를 때마다 다음 빈 자리로 스크롤·선택.
- 다운로드: 빈 자리 수 경고 + 확인.

## 비범위 / 남은 일

- 결제·크레딧 시스템 없음. AI 영상은 사용자의 Gemini 키로 청구.
