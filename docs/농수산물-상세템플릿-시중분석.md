# 농수산물 상세페이지 시중 템플릿 분석

> 작성: 2026-11-03 · 목적: 시중 패턴을 **정밀 분석 → 공통 구조만 뽑아 변형**해 내장 템플릿에 반영  
> 원칙: 특정 유료/구매 템플릿·포트폴리오 **디자인 복제 금지**. 반복되는 정보 구조·배치만 참고.

## 1. 조사 범위

| 출처 | 유형 | 본 것 |
|---|---|---|
| 기획공방 농수산물 포트폴리오 | 제작사 사례 | 샤인머스켓, 딸기, 절임배추, 방울토마토 등 섹션 흐름·카피 역할 |
| STUDIO-L 식품 상세 가이드 | 제작 가이드 | 5구간(배너→품질→구성→활용→신뢰) + 이미지 유형 |
| 산이사니 귀농 판매 가이드 | 구성 가이드 | 7단계(인트로→특징→생산자→디테일→후기→표) |
| 하랑마케팅 9단 구성 | 설득 순서 | 훅→카피→실사→신뢰→디테일→옵션→배송→고시→CS |
| 로켓페이지 농수산 템플릿 안내 | AI 템플릿 100종 메타 | 과일·채소·수산·선물세트, **7컷** 흐름 |
| 행운프레시 과일 CS 가이드 | 위탁셀러 실무 | 기대치 조절(크기·당도·등급·포장), CS 문구 |
| 상품정보제공고시 | 법정 | 농수산물 필수 표기 항목 |

Figma 구매 템플릿 파일 단위 숫자 분석은 **토큰·링크 미확보로 보류**. 공개 포트폴리오·가이드 기준으로 1차 반영.

## 2. 시중에서 반복되는 설득 흐름 (합본)

```
① 원물 비주얼 + 한 줄 약속(산지·중량·출고)
② 구매 전 확인 / 기대치 조절 (크기·등급·편차)
③ 산지·농가·과정 (신뢰)
④ 품질 근거 (당도·선별·인증·단면)
⑤ 구성·옵션·박스 양감
⑥ 세척·보관·레시피(활용)
⑦ 포장·보냉·배송 일정
⑧ 후기·재구매
⑨ Q&A · 교환 · 상품정보고시
```

로켓페이지류 **7컷**은 위 흐름을 짧게 압축한 것(첫화면·신뢰·가치·고민해결·확인·구매유도).

## 3. 농수산물에서만 강하게 나오는 블록

| 블록 | 왜 나오나 | 시중 예시 |
|---|---|---|
| 당도(Brix) + 측정 컷 | 과일 구매 기준 | 샤인머스켓 17브릭스 구간 |
| 정품 / 가정용 / 못난이 | CS·기대치 | 행운프레시 등급 풀어쓰기 |
| 크기 비교(동전·손·소중대) | “작아요” 문의 | 딸기·방울토마토 |
| 박스 펼침 + 과수 | “몇 개예요?” | 과일 5kg 구성 |
| 단면·과육 클로즈업 | 숙도·내부 상태 | 사과·감귤 |
| 수확→선별→당일 출고 | 신선 불안 | 샤인머스켓·농장 하루 |
| 다중 포장 / 보냉 | 파손·무름 | 4중 포장, 아이스팩 |
| 세척·보관 | 수령 후 활용 | 딸기·방울토마토 |
| 구매 전 확인(상단) | 예약·김장·출고일 | 절임배추 |
| 수산: 생물·선어·냉동·손질 | 상태 오해 | 수산 템플릿 공통 |
| 상품정보제공고시 | 법정 | 전 채널 |

## 4. 우리 템플릿과의 갭 (분석 전)

이미 있던 것: 산지·생산자, 선별, 크기 3단, 보관 3칸, 수확 달력, 포장 목록, 고시 표, 레시피.

약했거나 없던 것(→ 이번 변형으로 채움):

| 갭 | 반영 (구성 · 패턴 키) |
|---|---|
| 상단 스펙 한 줄 | 메인 비주얼 · `specbanner` |
| 구매 전 확인 박스 | 문제 제기 · `precheck` |
| 수확→출고 당일 | 호기심 유발 · `harvestship` |
| 당도 측정 | 상품 특징 · `brix` |
| 등급·기대치 | 상품 특징 · `grade` |
| 단면·과육 | 상품 특징 · `crosscut` |
| 박스 구성·과수 | 상세 정보 · `boxflat` |
| 보냉·완충 | 구매 안내 · `coldchain` |

교체한 약한 패턴: `spotlight`, `dim`, `secret`, `beforeafter`(특징), `pairing`, `tips`, `zebra`, `icons3`.

## 5. 변형 규칙 (복제 방지)

- 색·글꼴·장식·정확한 레이아웃 비율을 베끼지 않는다.
- “당도 숫자 + 측정 사진 + 편차 안내”처럼 **역할만** 가져온다.
- 사실 칸은 전부 `[ ]` / 안내 문구. 가짜 후기·가짜 수치 금지.
- 구성당 배치 10종 × 스킨 2 = 20개 유지 (`BUILTIN_VERSION` 갱신으로 재시드).
