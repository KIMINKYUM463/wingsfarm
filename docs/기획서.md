## 1. 시장 분석

### 1.1 경쟁 솔루션 지형도

| 범용 통합관리(OMS) | 사방넷, 플레이오토 | 650+ 채널 연동, 상품등록·주문/클레임 수집·송장·정산 | 월 5~8만원+ | 낮음 |
| 위탁셀러 발주 자동화 | 발주오라, 스윕, Nextflow | 주문수집→공급처별 발주서 자동생성→송장 회신→정산 | 월 수만원 | 낮음(범용) |
| 농산물 셀러 OMS | 팜프리 | 주문관리, 택배 API, AI 문자주문 분석 | 월 2.9만원~ | 중간 |

| 범용 도매몰 | 도매꾹, 오너클랜 | 대량 상품 DB, 공급사 등급 | 무료~구독 | 낮음 |

| 시세 정보 | KAMIS(농수산물유통정보) | 품목별 도·소매 가격 | 무료 | 높음(단, 판매 운영과 단절) |

### 1.2 시장에서 확인된 사실
- 위탁 발주 흐름(주문수집→발주서→송장→정산)은 **이미 레드오션**. 모든 솔루션이 "클릭 1번"을 내세움.
- 마진계산기는 **무료 단일 페이지 도구**가 대부분이며, 계산 결과가 상품 데이터와 연결되지 않음(일회성).
- 산지 공급사는 "매일 바뀌는 경락가로 마진을 직접 설계하라"고 하지만, **바뀐 시세를 내 판매가에 반영하는 도구는 없음**.
- 농산물 CS의 핵심은 파손·변질·지연. 공급사들은 "CS 전담 대응"을 셀링포인트로 내세울 만큼 셀러의 공포가 큼.
- 과일 위탁 가이드들은 "시즌 종료 시점을 미리 파악하라", "출고 지연 시 선제 안내하라"를 강조하지만 이를 **자동화한 툴은 없음**.

### 1.3 공백(기회) 정리

| # | 셀러의 실제 고통 | 기존 툴의 한계 | 우리의 해법 |
|---|---|---|---|
| G1 | 공급가(경락가)가 매일 바뀌어 모르는 새 **역마진** 판매 | 계산기는 일회성, OMS는 마진 개념 없음 | **시세 변동 → 전 상품·전 채널 마진 자동 재계산 + 역마진 경보 + 권장가** |
| G2 | 2kg/3kg/5kg 옵션 가격을 감으로 책정 → 큰 옵션이 오히려 손해 | 없음 | **중량 옵션 가격 설계기** (kg당 단가 역전 검사) |
| G3 | 상품명을 감으로 지어 검색·클릭이 안 잡힘 | 키워드툴만 있고 조합·추천은 없음 | **상품명 제조기** (연관 수식어 조합 + AI 추천) |
| G4 | 파손/상함 CS 응대 문구 작성이 매번 고민 | 범용 CS 수집만 존재 | **농산물 CS 도우미** (문의 캡처 → AI 답변·증빙 요청·판매자 할 일) |
| G6 | 제철 시작 전에 상세페이지·등록을 준비해야 하는데 놓침 | 없음 | **제철 캘린더 + 시즌 오픈 D-Day** |
| G7 | 면세(미가공 농산물) vs 과세(가공품) 부가세 차이를 계산기가 반영 못 함 | 대부분 과세 기준 | **면세/과세 구분 마진 계산** |

## 2. 제품 정의

- **제품명**: 윙스팜AI (영문 Wingsfarm AI)
- **타깃**: 무재고 농수산물 위탁판매 셀러(1~5인), 산지 공급처 5~30곳, 판매채널 2~6개
- **포지셔닝**: "발주 자동화 툴"이 아니라 **"농수산물 셀러의 수익 방어 툴"**
  - 경쟁사: *일을 줄여준다* → 우리: *일을 줄이면서 **돈이 새는 곳을 막는다***

### 2.1 핵심 차별 기능(신박 포인트) Top 5
1. **시세 연동 마진 재계산** — 공급가 한 번 수정하면 모든 채널 판매가의 마진이 즉시 재계산, 목표 마진 이하/역마진 SKU를 빨간불로 표시하고 권장 판매가 제시.
2. **중량 옵션 설계기** — kg당 공급단가 + 박스당 고정비 → 옵션별 권장가와 소비자 kg당 단가를 계산, "큰 옵션인데 kg당 더 비싼" 역전을 경고.
3. **상품명 제조기** — 메인 키워드 + 연관/프리셋 수식어로 조합하고, AI가 50자 이내 상품명 5개를 추천.
4. **CS 도우미** — 고객 문의 캡처를 붙여넣으면 AI가 유형·감정을 읽고 정책에 맞는 답변을 작성.
5. **제철 D-Day** — 품목별 시즌 시작까지 남은 날을 보여주고 "지금 상세페이지 준비할 품목"을 추천.

## 3. 기능 명세 (MVP 범위)

### 3.1 대시보드 `/`
- 네이버 데이터랩 쇼핑인사이트(식품 분야) 주간 검색 클릭 추이로 **급상승 TOP 5 · 많이 찾는 TOP 5 · 관심 식는 품목** 표시.
- API는 요청당 5개 키워드·요청 내 상대값만 주므로, 모든 요청에 기준 키워드(사과)를 넣어 전 품목을 같은 잣대로 환산.
- **지금 소싱하면 좋은 품목**: 작년 이맘때(364일 전 같은 주) 직전 4주 평균 대비, 그 뒤 +1개월/+2개월 평균 검색 상승률 순위.
  - 카드마다 작년 흐름 곡선(점선 = 작년 이맘때), 작년 피크 주차, 올해 인기(식품 전체 증감 보정 YoY) 표시.
  - 조회기간을 58주로 넓혀 "요즘 뜨는" 지표(최근 12주)와 같은 호출로 계산.
- 곧 시즌 오픈 품목 D-Day. API 키가 없으면 제철 정보만 표시(가짜 수치 없음).

### 3.1-1 키워드 분석 `/keywords` (아이템스카우트·판다랭크류)
- **네이버 공식 API만 사용.** 네이버 쇼핑 검색 API가 2026-07-31 종료(대체 API 없음)되어 상품수·경쟁강도(상품수÷검색수)·가격 분포·상위 상품·순위 추적은 제외.
- 요약: 월간 검색수(PC/모바일)·모바일 비중·월평균 클릭·클릭률·광고 경쟁(검색광고 API), 검색 피크 주(데이터랩).
- 연관 키워드: 검색광고 키워드 도구 결과(최대 50개), 검색수·광고 경쟁·클릭률 정렬. **황금 키워드** = 검색수 500 이상 & 광고 경쟁 낮음.
- **AI 분석**(키워드 분석 화면·대시보드 팝업의 "AI 분석" 버튼 → 오른쪽 로봇 패널): 키워드 리포트(검색량·월별 추이·고객층·연관 키워드·수식어)와 대시보드의 소싱 판단을 OpenAI에 넘겨 판정·핵심 인사이트·타깃 고객·후킹 카피·셀링 포인트·추천 상품명·메인/서브/태그 키워드·판매 타이밍·주의점을 정리. 데이터에 없는 수치는 만들지 않고 표시광고법 위반 표현은 금지. 키워드별 6시간 캐시, "다시 분석"으로 갱신, 전체/항목별 복사.
- 상품명 조합기: 메인 키워드를 포함한 연관 키워드에서 수식어만 추출(예: 해남절임배추 → 해남), 수식어별 검색수 합계로 크기 표시, 50자 권장 길이 표시.
- 고객층(데이터랩 성별·연령·기기), 1년 검색 추이.
- 대시보드 품목 팝업에 연관 키워드 미리보기 + 정밀 분석 링크.
- 각 데이터는 독립적으로 실패 처리 — 연결 안 된 API는 설정 안내만 표시.
- 일정: 데이터랩(쇼핑인사이트)은 NAVER API HUB로 이관 — 개발자센터 키는 2027-06-30 차단, 그 전에 교체 필요.

### 3.2 상품 등록 (설정 화면 안)
- 별도 메뉴 없이 설정 화면에서 SKU(상품명+옵션) 등록·수정·삭제: 공급처, 공급가, 셀러부담 택배비, 포장비, 면세 여부, 신선 여부, **채널별 판매가**.
- CS 도우미(문의 상품 인식)·가격·마진(상품 불러오기·전체 상품 마진표)·출고 지연 안내가 이 목록을 사용.
- 공급가를 바꾸면 날짜별 이력(최근 30건)이 쌓인다. 일괄 인상/인하 버튼은 제외(권장가 개별 적용으로 대체).

### 3.3 가격·마진 `/margin`
- 탭: **전체 상품(역마진 점검)** / **단일 상품** / **중량 옵션**. 단일·중량 탭은 채널·목표 마진율·면세 공통.
- 전체 상품: 등록 SKU × 판매 채널 마진을 한 표로 계산(설정의 목표 마진·광고비·CS 적립 기준). 역마진=빨강, 목표 미달=노랑. 공급가·판매가 칸에서 바로 수정, 공급가 추세선·변화율, **공급가 −30%~+50% 변동 시뮬레이션**, 셀마다 "권장가 적용". 대시보드 "역마진 경보" 카드에서 `/margin?tab=board`로 진입.
- 단일 상품: 공급가·택배·포장·판매가·광고비·CS손실 입력 → 순이익·마진율·손익분기가·목표마진 판매가·ROAS, 채널 비교표.
- 중량 옵션: kg당 공급단가 + 박스 고정비 + 옵션 중량 목록 → 옵션별 권장가·소비자 kg당 단가, **kg당 단가 역전** 경고. 가격 끝자리(900원/100원) 규칙.

### 3.4 상품명 제조기 `/titles`
- 메인 키워드 입력 → 검색광고 연관 키워드에서 수식어 추출(검색수 표시) + 산지·중량·등급·시즌 프리셋.
- 칩을 골라 조합하고 글자 수(50자 권장) 표시, 직접 수식어 추가, 복사.
- AI 추천: 서로 다른 각도 상품명 5개 + 주의점. "조합판에 적용"으로 수식어를 반영.
- 상품명 형식: `[꼬리표] 수식어 메인키워드 수식어` (예: [산지직송] 국내산 파김치 쪽파).

### 3.4-1 썸네일 제조기 `/thumbnails`
- 상품 사진 1장 + 상품명(사진 보고 **AI 채우기** 가능) → 메인 썸네일 **만들기/안 함**, 서브 **0~9장**을 골라 AI가 구성을 잡음(메인: 사람이 들거나 히어로 연출 / 서브: 수확·과즙·단면·포장·크기비교 등).
- 이어서 업로드 사진을 참고 이미지로 `images.edit`(기본 `gpt-image-1`, `OPENAI_IMAGE_MODEL`로 변경)로 정사각 이미지를 2장씩 병렬 생성. 장당 다시 생성·다운로드·**편집기**(글씨·배너·배지, 미리캔버스류).
- 결과는 보관함에 자동 저장(편집본 포함). 실제 사진 대체가 아니라 AI 생성물이며 요금·시간이 들 수 있음.

### 3.5 CS 도우미 `/cs`
- 탭: **AI 답변** / **출고 지연 안내**(탭을 바꿔도 대화 유지).
- 출고 지연 안내: 스토어명·상품·사유(기상 악화/선별 강화/주문 폭주/택배 물량/명절·연휴/산지 물량 부족)·새 출고일·보상(없음/적립금/덤) → 톡톡·문자·스토어 공지 3종 문구 즉시 생성(AI 미사용·요금 없음) + 보낸 뒤 할 일(채널 발송지연 처리 등).
- 대화형 챗봇 "윙스팜AI CS": 첫 인사("안녕하세요. 윙스팜AI CS입니다. 무엇을 도와드릴까요?") 후 판매자가 문의 캡처(최대 4장, Ctrl+V·끌어놓기) 또는 문의 글을 보내면 AI가 유형(파손, 상함·변질, 중량부족, 품질불만, 배송지연, 오배송, 일반 문의, 칭찬)·감정을 분석하고 답변 작성.
- 같은 대화에서 수정 요청("더 짧게", "재발송으로 안내해줘" 등 빠른 버튼 포함)과 일반 CS 질문 가능. 최근 20개 메시지를 문맥으로 전달하고 이미지는 가장 최근 캡처만 재전송.
- 판매자 보상 정책·말투 설정 반영, 요청할 증빙과 판매자 할 일 정리.
- 직접 작성 폼은 제외. 클레임 기록·공급처 스코어카드는 v1.7에서 `/claims`로 추가(13장).

### 3.6 제철 캘린더 `/season`
- 과일·채소·수산 주요 품목의 월별 제철 히트맵, 현재 월 강조.
- 시즌 오픈 D-Day, "상세페이지 준비 권장(시즌 30일 전)" 목록.

### 3.6-1 윙스팜AI 마케팅 `/marketing`
- 숏폼·쓰레드·카드뉴스·블로그·상세페이지·리뷰답글·톡톡/문자·라이브대본·**검색광고**를 **형식별 스튜디오**로 분리. 허브는 분자처럼 선으로 연결된 원형 버튼(드래그·부유 애니메이션).
- 카드뉴스·블로그는 글을 먼저 보여 주고, AI가 제안한 사진 자리 수를 안내한 뒤 **"사진 N장 만들기"를 눌러야** 이미지를 생성(요금 통제). 상품 사진을 올리면 표지·대표 사진은 생성하지 않고 그 사진을 사용. 자리별 개별 생성·재시도 가능.
- 모든 결과는 보관함에 자동 저장(이미지는 생성되는 대로 추가).
- **숏폼**: 길이(15/30/45초)·후킹 스타일·얼굴 출연 여부 → 타임라인 대본(화면/VO/자막/SFX)·폰 목업.
- **쓰레드**: 글 뼈대(산지 이야기/리스트/오해 깨기/하우투)·포스트 수 → 연속 포스트 UI·한 번에 복사.
- **카드뉴스**: 장수·디자인 무드·타깃 독자 → 4:5 슬라이드 프리뷰·아트디렉션·장별 컬러 힌트.
- **블로그**: 분량(800/1500/2500자)·톤(가이드/스토리/검색 칼럼/레시피) → 제목·본문 섹션·FAQ·CTA.
- **상세페이지**: 포커스(선물/신선/가성비/프리미엄) → 상단 카피·불릿·스토리·보관·CTA.
- **리뷰 답글**: 칭찬/보통/클레임/리뷰요청 → 붙여넣기용 답글 여러 버전.
- **톡톡·문자**: 출고/제철/재구매/이벤트 → 채널별 짧은 메시지.
- **라이브 대본**: 15/30/45분·호스트 톤 → 분 단위 진행표.
- **검색광고**: 목표(클릭/선물/신선/가성비) → 제목(15자)·설명(45자) 후보 + 글자수 검수(AI가 적은 값 대신 서버가 실제 글자 수를 다시 셈).
- 표시광고법 과장·효능 표현 금지.

### 3.6-2 검색 태그 `/tags`
- 상품명(+메모) → AI가 **스마트스토어 최대 10개** / **쿠팡 최대 20개** 검색태그 생성.
- 상품명에 이미 들어 있는 단어를 반복하지 않고 동의어·상태·산지·용도·시즌을 조합(쿠팡/스마트스토어 실무 가이드·오션셀러류 벤치마크).
- 쉼표·줄바꿈·공백 복사.

### 3.6-3 운영 체크리스트 `/ops`
- 실무팩·위탁판매 가이드의 **매일 5분 / 매주 30분 / 매월 2시간** SOP를 농수산물 위탁에 맞게 재구성.
- 출고·지연 선제안내·CS·시세·광고·상품명·제철 준비·정산·면세·백업 항목. 제철 민감 항목 배지.
- 완료 상태는 브라우저에 저장(주기별 키). 사이드에 이번 달 제철·곧 오픈 품목·빠른 이동 링크.

### 3.7 설정 `/settings`
- **연결 상태**(OpenAI·데이터랩·검색광고·비밀번호 잠금 설정 여부와 모델명, 키 값은 노출하지 않음), 채널 수수료 편집, 기본 비용(광고비율·CS적립률·목표마진), 공급처·상품, 데이터 백업/복원(JSON), 전체 데이터 초기화.

### 3.8 보관함 `/archive`
- 마케팅 9종·썸네일(편집본 포함)·검색 태그·AI 상품명 결과를 **IndexedDB**에 자동 저장(이미지가 커서 localStorage 대신). 최근 200건 유지.
- 종류별 필터·상품명 검색·펼쳐 보기·전체 복사·이미지 일괄 다운로드·삭제·전체 비우기.

### 3.9 공통: 작업 중인 상품
- 상품명 제조기의 "작업 상품으로", 썸네일의 AI 채우기, 각 화면 상품 입력이 하나의 "작업 중인 상품"을 공유 → 태그·썸네일·마케팅·출고 지연 안내에 자동 입력. 사이드바·대시보드에 표시.

## 4. 계산 로직 정의

```
매출(R)          = 판매가 + 고객결제 배송비
채널수수료(F)     = 판매가 × 판매수수료율 + 판매가 × 결제수수료율 + 고객배송비 × 배송비수수료율
원가(C)          = 공급가 + 셀러부담 택배비 + 포장비
광고비(A)         = 판매가 × 광고비율
CS손실적립(L)     = 판매가 × CS적립률
부가세(V)         = 과세상품: max(0, (R − C − F − A) / 11)   // 매출세액 − 매입세액(비용이 모두 VAT 포함 과세매입이라고 가정)
                   면세상품: 0
정산예정액        = R − F
순이익(P)         = R − F − C − A − L − V
마진율            = P / R
마크업            = P / 공급가
손익분기 ROAS     = 판매가 / (광고 전 이익) — 광고비를 이만큼 이하로 써야 적자가 아님
목표마진 판매가    = 이분 탐색으로 P/R = 목표마진 이 되는 최소 판매가 (올림 단위 적용)
```
> 프리셋 수수료는 2026년 공개 자료 기준 **참고값**이며, 채널·카테고리·등급에 따라 다르므로 설정에서 반드시 본인 값으로 수정한다.

## 12. v1.6 디자인 스타일 템플릿 (2026-10-30)

남의 템플릿(미리캔버스·캔바·크몽 등)은 저작권·이용약관 문제로 **복제하지 않았다.** 국내 상세페이지에서 반복되는 공통 패턴(가로 860px, 본문 30px 안팎·제목 56~72px, 섹션마다 라벨→제목→설명→사진 흐름, 벤토형 카드, 농산물은 생산자·산지 이야기, 선물·프리미엄은 짙은 바탕+명조)만 참고해 **윙스팜AI 고유 템플릿**을 새로 만들었다.

### 12.1 스타일 4종
| 스타일 | 제목 글꼴 | 기본 톤 | 특징 |
|---|---|---|---|
| 모던 | Pretendard 800 | 모노 그레이 | 왼쪽 정렬, 흰 바탕 위주, 둥근 카드 |
| 내추럴 | 나눔명조 | 포레스트 | 가운데 정렬, 사진 먼저(히어로), 지그재그 포인트, 짧은 선 라벨 |
| 프리미엄 | Noto Serif KR 700 | 미드나잇 네이비 | 각진 모서리, 선 카드, 사진 위 글자(히어로), 제목 밑줄 |
| 발랄 | Pretendard 900 | 코랄 | 알약 라벨, 크게 둥근 카드, 진한 바탕 섹션 많음 |
| 산지 다큐 (v1.9 추가) | Noto Serif KR 800 | 모카 브라운 | 사진 위 글자(히어로), 포인트 사진을 화면 끝까지 꽉 채움(`points: 'bleed'`), 왼쪽 정렬, 각진 모서리, 흰 바탕 위주 |

- 15가지 섹션 레이아웃 × 5스타일 = 템플릿 71개 (안내사항은 스타일 차이가 거의 없어 모던 1개만).
- 스타일 추가 방법: `src/shared/lib/designStyles.ts`(이름·설명·어울리는 톤·제목 글꼴) + `src/server/lever/templates/designStyles.ts`(배치 규칙) + 초안 화면 견본(`DesignStylePanel`의 `MOCK`) → `BUILTIN_VERSION`을 올리면 저장소 템플릿이 다시 만들어진다.
- 모든 바탕·배지·강조색에 팔레트 역할(`colorVar`)이 달려 있어 **색상 탭으로 한 번에 다시 칠할 수 있고**, AI 초안 페이지에 넣으면 그 페이지 팔레트로 자동으로 칠해진다.
- 후기·인증·배송·연락처 같은 사실 정보는 `[ ]` 자리표시로 비워 두었다(지어낸 정보 방지).

### 12.2 쓰는 곳
- **기획 초안 화면**: 하단 **디자인 · {스타일}** 버튼 → 스타일 고르기(미리보기 카드) + "어울리는 색으로 바꾸기". 고른 스타일로 섹션 미리보기·생성 결과가 바뀐다.
- **에디터 템플릿 탭**: 구성(메인 비주얼·핵심 포인트 …)마다 4스타일 템플릿이 추가됨. 상품명·카테고리만으로 템플릿 페이지를 만들 때도 한 페이지 안은 같은 스타일로 묶어 고른다.

### 12.3 한계
- 생성이 끝난 페이지는 스타일을 통째로 바꿀 수 없다(섹션별 템플릿 교체로 대신).
- 템플릿 문구는 예시 문구다. 상품에 맞는 문구는 AI 초안 생성이나 AI로 수정을 쓴다.
- 썸네일(SVG)은 웹폰트를 못 불러와 명조 계열이 기본 serif 글꼴로 보일 수 있다(캔버스에서는 제대로 나온다).

### 12.4 구성별 패턴 템플릿 160개 (v2.0)
스타일 템플릿은 "같은 배치 + 다른 옷"이라 구성마다 배치가 몇 가지 안 됐다. 국내 상세페이지 제작 가이드·포트폴리오(GENCY, 마이하루노트랩, 애드마케팁, 대시부스터, 기획공방 농산물 포트폴리오), 블록형 빌더의 섹션 분류(상세뚝딱 18종, 상세랩 26종), Baymard 상품 페이지 연구를 훑어 **반복되는 배치 패턴만** 뽑아 새로 그렸다(남의 디자인 복제 없음).

- 흐름: 후킹 → 공감(문제) → 해결·근거 → 불안 해소 → 구매 유도. 농산물은 산지·생산자, 당도(Brix), 크기 비교, 수확→출고, 포장 단면, 못난이 고지, 보관·손질, 레시피가 자주 나온다.
- 구성 8개 × 배치 10종 × 스킨 2개 = **160개**(구성당 20개). 스킨은 기존 5스타일(모던 흰 바탕 / 내추럴 연한 바탕 / 프리미엄 짙은 바탕 / 발랄 진한 바탕 / 산지 다큐 흰 바탕) 중 배치마다 2개를 돌려 쓴다(`skinsOf`).

| 구성 | 배치 10종 |
|---|---|
| 메인 비주얼 | 좌우 분할, 숫자 강조, 사진 위 글자, 도장, 띠, 스포트라이트, 콜라주, 체크 3줄, 제철, 파노라마 |
| 문제 제기 | 말풍선, 체크리스트, X 표시, 인용, 번호, 통계, 사진 격자, 채팅, 어두운 화면, 비교 |
| 호기심 유발 | 타임라인, 인터뷰, 산지 소개, 잡지형, 이유 3가지, 과정, 편지, 사진 설명, 비밀, 하루 일과 |

### 13.3 기능 메모
- **발주서**: 머리글 자동 인식(스마트스토어·쿠팡·11번가 등 동의어) → 틀린 칸만 사용자가 수정. 상품명·옵션을 내 상품에 한 번 연결하면 별칭으로 기억. 공급처마다 발주서 열 양식·출고 마감 시각·출고 요일·신선 출고 금지 요일을 설정에 저장. 연결된 주문은 주문번호+상품 id로 **중복 없이** 장부에 넣는다.
- **AI 문자주문**: 문자·카톡 주문을 OpenAI로 표로 정리. 개인정보가 들어가므로 화면에 보관 정책 경고를 띄운다.
- **장부 부가세**: 일반과세자 기준 대략치. 수수료·광고비처럼 과세·면세 매출에 같이 쓴 비용은 **과세 매출 비율만큼만** 매입세액으로 본다(공통매입 안분). 간이과세·의제매입세액 공제는 반영하지 않는다.
- **스코어카드 등급**: 클레임률 1% 미만 A · 3% 미만 B · 6% 미만 C · 그 이상 D(경험치). 판매 30개 미만이면 "참고용" 표시.
- **KAMIS**: `.env.local`에 `KAMIS_CERT_KEY`, `KAMIS_CERT_ID`(무료 발급). 없으면 설정 안내만 보인다.
- **소싱 시즌 매칭**: 상품명에서 제철 품목을 찾을 때 흔한 표기(샤인머스켓)와 띄어쓰기를 허용하고, 여러 개가 걸리면 가장 긴 이름을 쓴다.

### 13.4 한계
- 마켓 주문·송장 **자동 수집·자동 전송은 없다**(파일 내려받기·올리기는 사용자가). `.xls`(구형 엑셀)는 읽지 못해 `.xlsx`·CSV로 저장해 달라고 안내한다.
- 장부·클레임·소싱 데이터는 이 브라우저(localStorage)에만 있다. 설정의 백업을 써야 한다.
- 공휴일 표는 직접 넣은 값이다. 임시공휴일·택배 없는 날은 사용자가 추가해야 한다.
- 리뷰 빠른 집계는 키워드 규칙이라 반어·오타는 놓친다. 정확한 판단은 AI 분석으로.

## 14. v1.8 상세페이지 고도화 — 사진 연출 선택 · 맨 위 움직이는 컷 (2026-10-30)

- 서버 PC에 **ffmpeg** 필요(PATH 또는 `.env.local`의 `FFMPEG_PATH`). 없으면 움직이는 컷만 안내 메시지로 막히고 나머지는 그대로 동작.

- GIF는 10MB 이하로 자동 축소(마켓 한도는 미확인).

### 14.3 점검 보완 (2026-10-30)
- 네이버쇼핑은 2026-07-10부터 AI로 만든 상세페이지 이미지에 AI 활용 표시를 요구한다(신선식품은 8월 완화 후 "사용 허용 + 표시 의무"). 그런데 AI 고지 섹션이 긴 구성에만 있어 짧은 구성에서 빠졌다 → AI 사진 모드면 구성 길이와 상관없이 맨 끝에 넣고, 빈칸 모드면 뺀다.
- 시중 도구 비교 기사에서 AI가 가장 많이 지어낸 "오늘 출발"류 배송 약속과 고객센터 번호·운영 시간을 사실 검사 규칙에 추가했다.
- 네이버 기준의 "이미지 안 또는 가장 가까운 위치" 표시: AI로 만든 사진(생성 단계·에디터에서 만든 것 모두, 예전 사진 포함) 왼쪽 아래에 **"AI 연출 이미지"** 배지를 그린다. 캔버스·JPG/PNG/WEBP·HTML·움직이는 컷 GIF에 모두 들어간다. 서버가 AI 에셋 주소에 `ai=1`을 붙이고 캔버스가 그걸 보고 그린다(`src/shared/lib/aiImageLabel.ts`). 내 사진은 표시하지 않는다. 배지는 끌 수 없다.
