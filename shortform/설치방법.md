# 설치 방법 (새 컴퓨터에서)

이 압축 파일에는 코드와 레퍼런스 분석 자료만 들어 있습니다. API 키, 만든 영상, 상품 사진은 들어 있지 않습니다.

1. **Python 3.12**와 **ffmpeg**를 설치합니다.

   ```
   winget install Python.Python.3.12
   winget install Gyan.FFmpeg
   ```

2. 이 폴더에서 Python 패키지를 설치합니다.

   ```
   python -m pip install -r requirements.txt
   ```

3. 모션그래픽을 쓰려면 **Node.js**를 설치하고, `motion` 폴더에서 패키지를 설치합니다.

   ```
   winget install OpenJS.NodeJS.LTS
   cd motion
   npm install
   ```

   처음 모션 영상을 만들 때 렌더링용 브라우저를 자동으로 내려받습니다.

4. `.env.example`을 복사해 `.env`로 저장하고 키를 넣습니다.
   - FAL_KEY: AI 장면 사진·영상
   - PEXELS_API_KEY: 무료 풍경 영상
   - REPLICATE_API_TOKEN: fal 실패 시 대체
   - GEMINI_API_KEY: Gemini 목소리

5. `스튜디오_실행.bat`을 더블클릭합니다. 쓰는 법은 `사용법.md`에 있습니다.
