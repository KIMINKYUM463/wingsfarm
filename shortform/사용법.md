# 숏폼 생성기 사용법

## 숏폼 스튜디오 (웹 화면, 가장 쉬운 방법)

`스튜디오_실행.bat`을 더블클릭하면 브라우저에 스튜디오가 열린다. 명령어로 열려면 다음을 실행한다.

```
python studio\server.py
```

주소는 `http://127.0.0.1:8765`이고, 이 PC에서만 열린다. 끄려면 검은 창을 닫는다.

**레퍼런스 화면**
- 조회수 상위 농수산물 쇼츠 55개를 형식, 품목, 훅 유형으로 걸러 볼 수 있다.
- 카드를 누르면 영상이 재생되고, 다음 내용이 함께 나온다.
  - 훅 공식
  - 가져올 점
  - 템플릿 구조
  - 이 템플릿으로 만든 참외 샘플

**만들기 화면**
1. 템플릿과 레퍼런스를 고른다. 레퍼런스의 훅 공식이 문구 초안에 쓰인다.
2. 상품명과 사진 한 장을 넣고 "상품 저장 · 사진 분석"을 누른다.
   - AI가 사진을 보고 분류와 AI용 영어 설명을 채운다.
   - 아이폰 사진(HEIC)도 그대로 올리면 된다. 스튜디오가 JPG로 바꾸고, 휴대폰 사진의 회전 정보도 반영한다.
   - 산지, 구성, 가격, 판매자 메모는 선택이다. 메모에 적은 사실만 문구에 숫자로 쓰인다.
3. "AI 문구 초안 만들기"를 누르고 고칠 곳을 고친다.
   - `*단어*`는 영상에서 노란색으로 강조된다.
   - 장면마다 쓸 그림을 드롭다운에서 바꿀 수 있다.
   - 오른쪽 폰 화면에서 배치를 미리 본다.
4. 방식을 고르고 "영상 만들기"를 누른다.
   - **AI 장면**: 처음 쓰는 장면만 비용이 든다. 화면에 새로 만들 장면 수가 나온다.
   - **사진만**: 무료이고 1분 안팎이다.

**레퍼런스 해부와 "이 구조 그대로 내 상품으로" (레퍼런스 복제)**
- 레퍼런스를 열면 Claude가 그 영상을 장면 단위로 해부한 결과가 나온다.
  - 유튜브가 공개하는 프레임 5장(시작·25%·50%·75%·표지)과 제목을 보고 분석한다. 영상 파일은 내려받지 않는다.
  - 장면 순서, 장면마다 전달하는 내용, 자막 방식(핵심어 강조색), 내레이션/자막만, 화면 배치, 템포, 음악 분위기, 잘 된 이유를 보여 준다.
- "이 구조 그대로 내 상품으로"를 누르면 같은 장면 수·순서·라벨·자막 방식으로 내 상품 영상을 만든다.
  - 장면마다 왼쪽에 레퍼런스 프레임, 오른쪽에 내 문장과 장면 그림이 나란히 나온다.
- 레퍼런스 화면 위 칸에 유튜브 쇼츠 주소를 붙여 넣으면, 내가 찾은 영상도 바로 해부해서 목록에 추가한다.

**만든 뒤 점검과 수정**
- **실물 일치 점검**: AI 장면을 다 만들면 Claude가 장면 사진과 올린 상품 사진을 비교해 10점 만점으로 매긴다.
  - 7점 미만이면 "이 장면 다시 만들기" 버튼이 나온다. 생물 상품은 "영상과 달라요"가 반품으로 이어지기 때문이다.
  - 올린 이미지가 실제 사진이 아니라 그림이면 사진 분석 단계에서 미리 알려 준다.
- **광고 문구 점검**: 질병·효능, 다이어트, "2배" 같은 근거 없는 수치, 최상급, 인증 표현, 다른 업체 비교를 문장을 쓰는 동안 바로 표시한다.
  - 식품 표시·광고법에서 자주 걸리는 표현을 기준으로 한 것이고, 법률 검토를 대신하지는 않는다.
  - 판매자 정보(구성·가격·메모)에 없는 무게·당도·개수·가격·날짜 숫자도 "AI가 지어낸 값일 수 있어요"로 표시한다. 맞는 숫자면 상품 메모에 적어 두면 된다.
- **AI 생성 장면 포함 표시**: AI 장면을 쓴 영상은 오른쪽 위에 작게 표시한다(기본으로 켜짐). 플랫폼 정책과 AI기본법에 대비한 것이다.
- **말로 고치기**: 결과 아래 입력칸에 "첫 문장을 더 궁금하게", "남자 목소리로, 음악은 잔잔하게", "2번째 장면 빼 줘"처럼 쓰면 Claude가 설정을 고치고 바로 다시 만든다.
  - 이미 만든 AI 장면은 다시 쓰므로 비용이 거의 들지 않는다.

**완성 뒤 버튼**
- **📋 올릴 글 만들기**: 유튜브 쇼츠·인스타 릴스·틱톡·네이버 클립용 제목, 설명, 해시태그를 한 번에 쓴다. 플랫폼마다 복사 버튼이 있다.
- **첫 문장만 다른 3편 (A/B)**: Claude가 질문형·경고형·숫자형 훅 3개를 쓰고, 나머지 장면은 그대로 둔 채 3편을 만든다. 장면을 다시 쓰므로 AI 장면 비용이 들지 않는다.
- **내 사진으로 바꾸기 (무료)**: 실물 점검에서 7점 미만인 장면을 올린 사진 컷으로 바꿔 다시 만든다.
- 문구는 판매자를 위탁판매자로 보고 쓴다. 메모에 직접 재배라고 적지 않으면 "저희 농장", "직접 키운" 같은 말을 쓰지 않는다.

**영상 옵션**
- 배경음악은 밝은·경쾌한·잔잔한·시장활기 4가지다. AI로 한 번 만들어 `studio\data\bgm`에 저장해 두고 계속 쓴다.
  - 자막만 나오는 영상은 음악을 크게, 내레이션 영상은 작게 깐다.
- 목소리는 6가지 중에서 고른다.
  - **여성·남성**: 무료(edge-tts). 연습용이다. 배포·판매용으로는 Gemini 목소리를 쓴다.
  - **Gemini 여성 · 또렷한 / 밝은, Gemini 남성 · 활기찬 / 차분한**: Google Gemini TTS(`gemini-3.8-flash-tts`). 더 자연스럽다. 문장당 1원 안팎(추정)이다.
  - Gemini 키는 `.env`의 `GEMINI_API_KEY`에 있다. 같은 문장·목소리는 `studio\data\tts_cache`에 저장해 두고 다시 쓴다(A/B·다시 만들기 때 비용 0).
  - 결과 길이가 이상하면(끝이 잘리거나 엉뚱한 말이 붙으면) 자동으로 다시 만든다. Gemini가 안 되면 무료 목소리로 대신 만든다.
  - Gemini는 단어별 타이밍을 주지 않아서, 자막 타이밍은 소리의 쉬는 구간과 어절 길이로 맞춘다.
- 문구의 숫자는 "5kg", "50~60개", "13~15Brix"처럼 아라비아 숫자로 쓴다. 목소리는 "5킬로그램", "50에서 60개"로 바꿔 읽고, 자막도 숫자로 보인다.
- 자막만 나오는 복제 영상은 레퍼런스 템포를 따르되, 문장을 다 읽을 시간(1초에 7자 정도)은 남긴다.

**✨ 모션그래픽 (베타)**
- 카드를 뺀 모든 템플릿(판매형·레퍼런스 복제 포함)에서 "✨ 모션그래픽"을 켜면 같은 문구로 움직이는 영상을 만든다.
  - 보관 경고: 빨간 X·초록 O 도장이 쾅 찍히고 화면이 살짝 흔들린다.
  - VS 비교: A 이름표는 왼쪽에서, B 이름표는 오른쪽에서 들어오고, B가 나올 때 VS가 찍힌다.
  - 물량 리빌: 숫자가 0부터 올라가다 멈추며 튄다(개수 칸에 숫자가 있을 때).
  - 자막만 나오는 레퍼런스 복제: 문장 전체가 어절마다 차례로 튀어나온다.
  - 말하는 단어부터 글자가 튀어나오고, 강조어에는 형광펜이 그어진다.
  - TIP 배지가 회전하며 튀어나오고, 진행 막대·체크 표시·상품 위 원형 강조가 들어간다.
  - 장면이 바뀔 때 강조색 판이 휙 지나가고, 사진은 장면마다 다른 방향으로 천천히 움직인다.
  - 마지막 장면에 가격표가 올라오고, 원래 가격에 줄이 그어지며 숫자가 판매가로 내려간다(상품 정보에 가격이 있을 때).
- 엔진은 Remotion(코드로 영상을 만드는 도구)이고 `motion` 폴더에 있다. 직접 실행: `python make_motion.py <상품폴더> --config 설정.json`
- 글꼴은 재배포할 수 있는 프리텐다드(OFL)를 쓴다.
- 처음 한 번은 Node.js가 필요하다(이미 설치됨). 영상 하나에 50초 안팎 걸린다.
- Remotion은 개인·직원 3명 이하 회사는 무료이고, 그보다 크면 회사 라이선스가 필요하다.

**일주일치 기획**
- 상품을 저장한 뒤 "✨ 일주일치 기획하기"를 누른다.
- Claude가 해부해 둔 레퍼런스 중에서 이 상품에 맞는 5편을 골라 요일·올릴 곳·목표·이유를 짠다. 정보형을 절반 이상 넣는다.
  - 깎기 ASMR·현장 리포트처럼 직접 찍어야 하는 형식은 후보에서 뺀다.
- 고른 영상은 문구까지 자동으로 쓰고 한꺼번에 만든다. 결과는 "만든 영상"에서 요일 표시와 함께 보이고, 하나씩 열어 고칠 수 있다.

**만든 영상 화면**
- 지금까지 만든 영상을 보고 저장할 수 있다.
- 실물 점검이나 문구 점검에 걸린 건수가 함께 표시된다.
- "열어서 고치기"를 누르면 같은 설정으로 만들기 화면이 열린다.
- "목록에서 빼기"는 다 만든 영상이나 실패한 영상을 목록에서만 뺀다. 영상 파일은 output 폴더에 남는다.
- 스튜디오가 이미 켜져 있을 때 `스튜디오_실행.bat`을 다시 눌러도 괜찮다. 새로 켜지 않고 열려 있는 스튜디오 화면을 띄운다.

**레퍼런스 라이브러리 다시 모으기**
- `python studio\tools\collect_refs.py`: 품목 120여 개 × 형식 3가지와 일반 검색어 46개로 유튜브 쇼츠를 검색해 후보를 모은다.
  - 이미 검색한 검색어는 건너뛴다.
- `python studio\tools\build_library.py --analyze 160`: 후보를 Claude가 제목으로 분류해 쓸 만한 것만 고르고, 조회수 상위 160개를 해부해 둔다.
  - 품목 × 형식마다 3개까지 고른다.

**파일 위치**
- 결과물은 `output\상품명_템플릿_날짜시각.mp4`로 저장된다.
- 상품은 `products\상품명\`에 저장된다. 사진은 `00_studio.jpg`, 장면 캐시는 `_clips`, 실행 설정은 `_runs`에 들어간다.

**레퍼런스와 템플릿 고치기**
- 레퍼런스를 추가하려면 `studio\references.json`의 `items`에 유튜브 영상 id와 템플릿 이름을 적는다.
- 템플릿의 입력 칸은 `templates\*.json`의 `fields`에서 바꾼다.

## 영상 소스 (API 키)
`.env` 파일에 키를 넣으면, 레퍼런스 사진을 바탕으로 장면 영상을 자동으로 만들거나 찾아온다.

| 장면 | 소스 | 필요한 키 |
|---|---|---|
| 후킹(단면) · 디테일 · 먹는 장면 · 박스 히어로 | AI: 레퍼런스 사진으로 9:16 장면 사진을 만든 뒤 5초 영상으로 변환 (nano-banana-pro → Kling O3) | `FAL_KEY` (유료) |
| 산지(밭·과수원·바다) · 상품 일반 컷 | Pexels 무료 세로 영상 | `PEXELS_API_KEY` (무료) |

- 키가 없거나 생성에 실패한 장면은 레퍼런스 사진에 줌 효과를 넣어 대신 만든다.
- 만든 클립은 `상품폴더\_clips\`에 저장된다. 후킹만 다른 버전 3개가 같은 클립을 쓰므로 AI 비용은 상품당 한 번만 든다. 다시 만들려면 `_clips` 폴더를 지운다.
- Pexels 영상을 쓴 경우 `output\상품명_영상출처.txt`에 촬영자 출처가 남는다.
- 사진만으로 만들려면 product.json에 `"photos_only": true`를 넣는다.
- 상품명이 내장 목록(참외, 사과, 귤, 대게, 한우 등)에 없으면 `"en_name"`(AI용 영어 설명)과 `"stock_query"`(스톡 검색어)를 직접 적는다.

1. `products\` 안에 상품 폴더를 만든다 (예: `products\영덕 대게\`).
2. 사진을 넣는다. 파일명 순서대로 쓰인다.
   - `01.jpg`: 후킹 컷 (가장 맛있어 보이는 사진: 단면, 클로즈업)
   - `02.jpg`: 산지·원물
   - `03~05.jpg`: 특징을 보여주는 디테일
   - 그다음: 먹는/조리 장면
   - 마지막: 포장 박스 (가격 카드 배경으로 쓰임)
3. (선택) `product.json`을 넣는다. 없으면 폴더 이름이 상품명이 되고 카테고리는 과일로 처리된다.

```json
{
  "name": "영덕 대게",
  "category": "수산",
  "origin": "경북 영덕",
  "features": ["살이 꽉 찬 박달대게만", "산지에서 바로 쪄서 발송"],
  "price": 59000,
  "original_price": 79000,
  "unit": "2kg · 무료배송",
  "hooks": ["질문인용", "공감", "한정"]
}
```

- `category`: 과일 / 채소 / 수산 / 축산 / 가공
- `hooks`: 질문인용 / 공감 / 한정 / 생산자 / 가격 (가격은 price가 있을 때만)
- `tag` (선택): 왼쪽 위에 작게 계속 표시할 문구 (예: "○○농장"). 없으면 아무것도 표시하지 않는다.
- `features`는 최대 3개까지, 말하듯이 짧게 쓴다. 이 문장이 그대로 나레이션과 자막이 된다.

4. (선택) 저작권 없는 배경음악을 `bgm.mp3`라는 이름으로 상품 폴더에 넣는다.
5. 실행한다:

```
python make_short.py "products\영덕 대게"
```

결과는 `output\`에 생성된다. 후킹만 다른 영상 3개와 각각의 대본 txt가 나온다.


## 정보형 영상 (고르는 법·보관법)

판매형 외에 저장·공유가 잘 되는 정보형 영상을 만들 수 있다. product.json에 `tips`를 넣고 `--format tip`으로 실행한다.

```json
"tips": [
  {

    "outro": "저장해 두고 장 볼 때 꺼내 보세요. 이렇게 골라 담은 참외, 프로필 링크에 있어요."

```

```
python make_short.py "products\참외" --format tip
```

- `title`: 영상 내내 위쪽 노란 바에 표시된다. 팁마다 TIP 1, 2, 3 배지가 붙는다.
- 장면 소스는 기본 AI 장면(ai:hook, ai:detail, ai:crave, ai:hero)이나 `stock:origin`을 쓴다.
- 새 장면이 필요하면 `shots`에 추가한다. `{en}`은 영어 품목명으로 바뀐다. 장면 하나당 AI 생성 비용이 한 번 든다.

```json
"shots": {"hold": ["A hand picking up one whole {en} ... (사진 설명)", "The hand gently lifts ... (움직임)"]}
```

- 스톡 검색어를 바꾸려면 `stock_shots`에 넣는다: `"stock_shots": {"origin": ["korean melon greenhouse"]}`
- 팁 내용은 사실이어야 한다. 효능(혈압, 다이어트 등)은 쓰지 않는다.
