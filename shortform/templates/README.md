# 숏폼 템플릿 카탈로그

2026-10-31 리서치. 유튜브 쇼츠 검색어 48개(국내 40, 해외 8)의 조회수 상위 영상과 틱톡 탐색 페이지 3개(과일 고르는 법, 산지직송, 수산시장)를 모았다. 그중 상위 영상 10여 개는 직접 재생해 화면 구성을 확인했다. 인스타그램은 로그인이 필요해 수집하지 못했다.

## 핵심 발견

1. **정보형이 판매형보다 수십~수천 배 더 본다.** 유튜브 "산지직송 과일" 쇼츠는 대부분 100~4천 회다. 같은 품목의 고르는 법·손질법은 100만~2,500만 회다.
   - 수박 고르는 법 3가지: 2,582만
   - 갈치 손질: 1,716만
2. **틱톡은 예외적으로 단순 상품 영상도 터진다.** 제철김PD의 햇 호박고구마(한 줄 캡션)는 130만이다. 틱톡에서는 짧은 루프형 판매 영상을 매일 올릴 가치가 있다.
3. **국내 정보형의 화면 표준은 "레터박스"다.**
   - 위쪽 검은 영역에 큰 제목 2줄을 넣는다(1줄 흰색, 2줄 노란색).
   - 가운데는 4:5 영상이다.
   - 아래는 노란 정보 바(전화번호, 링크 안내)다.
   - 예: 괴산 절임배추 104만, 노량진 연어 1,240만, 참외 보관 218만.
   - 제목이 영상 내내 떠 있어서 저장해 뒀다 다시 볼 때 무슨 영상인지 바로 보인다.
4. **자막은 핵심어만 색을 바꾼다.** 흰 글씨에 핵심어 하나만 노랑이나 초록으로 강조한다(수박 고르는 법, 사과 영상).
5. **상위 영상 길이는 14~59초다.** 1위 수박 영상은 15초다. 짧을수록 끝까지 보는 사람이 많다.
6. **권위 있는 화자가 효과를 낸다.** 비닐하우스 안의 농부, 35년 과일장수, 과일가게 사장님처럼 "현장 사람이 알려준다"는 설정이 반복된다.

## 훅 공식 (상위 영상 제목에서 뽑음)

| 유형 | 공식 | 실제 예 (조회수) |
| --- | --- | --- |
| 부정 경고 | 제발 이런 {품목} 사지 마세요 / {행동}할 때 절대 {X} 하지 마세요 | 제발 이런 사과 사지마세요 (249만), 참외 보관할때 절대 베란다에 두지마세요 (218만) |
| 숫자 리스트 | {품목} 고르는 법 N가지 / 딱 N가지만 보세요 | 수박 고르는 법 3가지 (2,582만) |
| 다들 속았다 | 전국민이 속았습니다 / 의외로 모르는 / 98%가 모르는 | 수박 고르는 법(전국민이 속았습니다) (400만) |
| 내부자 권위 | 업자들만 아는 / 10년 장사꾼도 / 과일가게 사장님이 알려준 | 10년 장사꾼도 울고 간 과일 고르는 비법 (316만) |
| 실패 없음 | 이것만 보면 실패 없습니다 / 발견하면 무조건 사오세요 | 이 수박 발견하면 무조건 사오세요 (456만) |
| 질문 리빌 | 얼마나 들어갈까요? / {X} 달라고 했더니..?! | 괴산 절임배추 얼마나 들어갈까요? (104만) |
| 쉬움 | 가위 필요 없어요 / 10초면 끝 / 이렇게 쉬웠어? | 홍게다리 가위 필요 없어요 (930만) |
| 가격 대비 | {싼 것} vs {비싼 것} | 5천원 소고기 VS 10만원 소고기 (351만) |

**쓰지 말 것:**
- "독이 됩니다", "당도 2배" 같은 건강·효능이나 과장된 수치 (표시·광고법 위반 소지)
- 특정 업체나 마트를 깎아내리는 비교

"내부자 권위" 훅은 사실일 때만 쓴다. 위탁판매라면 "산지 사장님께 물어봤어요"처럼 출처를 밝히는 식으로 바꾼다.

## 촬영 템플릿 가이드 (AI로 대신하기 어려운 것)

**깎기ASMR**: 휴대폰은 세로로, 칼과 손이 화면 가운데 오게 고정한다.
- 소리가 핵심이다. 음악은 넣지 않고 마이크를 칼 가까이 둔다.
- 컷 1: 통째로 든 모습 2초
- 컷 2: 깎는 장면 10~30초 (끊지 않는다)
- 컷 3: 접시에 담긴 완성 3초
- 제목 예: "과일가게 이모의 참외 깎기"

**현장리포트**
- 컷 1: 현장 전경과 질문 자막 ("새벽 4시 가락시장, 참외 경매 현장")
- 컷 2: 경매·선별·포장 손 장면 각 3~5초
- 컷 3: 생산자나 경매사의 한마디 (얼굴이 나오면 신뢰가 크게 오른다)
- 촬영한 영상은 상품 폴더에 넣고 `"source": "file:경매.mp4"` 처럼 지정한다 (다음 개선 항목).

## 영상 만들기

product.json에 `videos`를 추가하고 실행한다.

```
python make_template.py "products\참외"
python make_template.py "products\참외" --only T1_고르는법
```

필드 예시는 `products\참외\product.json` 의 videos를 참고한다.

- `title1`, `title2`: 레터박스 제목 두 줄. 2줄째가 노란색이다.
- `info`: 아래 노란 바. 비우면 템플릿 기본 문구가 들어간다.
- 문장 안 `*단어*`는 노란 강조 자막이 된다. 한 문장에 1~2개만 쓴다.
- `items` / `steps` / `wrong` / `right`: `["문장", "장면 소스"]` 목록
- 장면 소스:
  - `ai:hook`, `ai:detail`, `ai:crave`, `ai:hero`
  - product.json `shots`에 추가한 `ai:이름`
  - `stock:origin`
- 물량리빌: `count`, `unit`, `reveal`
- 비교: `a_name`, `a_say`, `a_source`, `b_name`, `b_say`, `b_source`, `verdict`
- 짧은루프: `line1`, `line2`, `source1`, `source2`
